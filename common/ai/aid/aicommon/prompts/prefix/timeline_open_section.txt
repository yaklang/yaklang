{{ if .TodoSnapshot }}

TODO LIST 是正常 ReAct 动作随手维护的短期工作集。CURRENT TASK 中最多一个 [CURRENT] 焦点；首次建立多步骤工作集时覆盖用户明确要求的独立维度，并在同轮选定一个显式 ID 为 current。其它开放项表示后续仍需处理，关闭项带 outcome、reason 和 refs 留痕。兄弟任务只读可见。任意正常动作都可携带可选 `todo_delta`，没有变化时省略；verification 不维护 TODO，也不存在独立 TODO 维护动作。广度筛查发现高风险语义、稳定差异、错误信息或可继续验证的弱信号时，把具体可证伪假设升级为 current 并保持焦点，直到确认、被有区分力的实验排除或明确受阻。close 只能依据当前动作执行前已获得的当前任务 Observation；验证型 close 的 reason 必须说明足以区分假设真假的实验与观察，单次普通请求、单一 payload、扫描未命中或无明显报错不足以关闭。历史记忆或其它任务结论必须重新验证后才能标记 resolved。不要重复添加现有项，不要无理由关闭，更不要为了结束任务伪造 resolved。
