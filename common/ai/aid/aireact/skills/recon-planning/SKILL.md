# 攻击面侦查（Recon）

高效、快速地探索攻击面并打点：先看清有什么，立刻测该测的；遇到值得深入的点，丢给子 Agent 挖，结果回来后主线继续拆 todo。短耗时同步做，长耗时异步做。整场要持续有新入口、新线索、新结论，禁止空等。

指纹、版本、扫描器命中不是漏洞。高严重问题多半来自系统覆盖，不是更花的 payload。

## 硬约束

1. **授权边界**：只测用户给出的目标。范围没说清时，使用“默认全站策略”。
2. **默认全站**：用户给的是资产，不是单条 URL。子域、子系统、同 IP 其他站点、证书/跳转/JS 里的同产品 host 都要测。只有用户明确说只测某个漏洞或某个点，才缩小范围。任务长不是缩范围的理由。
3. **跟着入口走**：没探测当前目标之前，不去打无关产品线。入口带出的其他 host、登录或功能跳转到的网关和 API 域、同一 host 下的其他 path，都要跟，可以使用todo来设置代办以跟踪。
4. **眼前的先测完**：当前目标上已经发现、还能访问的入口没处理完，不开另一摊无关扫描。新发现的关联域名先写入清单，眼前的测完再扩过去。禁止只收集域名、一个都不探测。
5. **短的当场做，长的丢出去**：发请求、读响应、判断能否访问、记基线、打第一枪——主线立刻做。扫子域、扫端口、深爬、猜目录、翻历史和代码仓、跟长利用链——交给子 Agent 异步做。主线不强制等待它们结束。
6. **子 Agent 回来立刻拆任务**：带回的资产和线索马上写入清单，并新建或拆开 todo：测什么、测到哪、还缺什么。禁止只当日志存着。
7. **发现立刻记**：新资产、新入口、新线索立刻进清单和 todo，不要攒着写。

## 1. 持续产出

```
观察入口 → 短打点（同步）→ 分类：浅结论 / 可深入 / 长耗时扩张
                ↑                         ↓
                └── 回流结果 → 加资产 + 加 todo ── 子 Agent 异步挖
```

- **高性价比先发**：点名目标的常规 Web 端口与用户指定端口立刻 HTTP 探测，先发再分析。
- **看见就分类，分类就打点**：有登录就记认证面；有 ID/租户字段就记对象级授权；有文件/URL 参数就记文件或服务端请求；有搜索/过滤就记注入面；有管理/文档/调试口就当场浅探。浅打点要有基线对照，不要空报“存在某某功能”。
- **可深入就外派**：同一点需要跟会话、跟多身份、跟利用链、跟大量枚举时，拉子 Agent 挖，主线换下一条活入口，不堵在这一处。
- **被动与主动并行**：公开解析、证书、搜索、历史、代码仓立刻外派。端口、爬取、目录猜测、TLS 与入口探测同时进行。
- **进站先说清这摊**：几行写清业务、核心对象、没登录能碰到哪一层。说不清先看首页/跳转/JS。
- **优先级是顺序不是砍范围**：先跟暴露面大、有管理/接口/数据服务、有组件线索的点。其余不丢，排后或外派。

## 2. 观察：有什么

每条资产落到：

```
名字 → 地址 → 端口 → 服务 → 入口
Web/接口再落到：路径、参数、表单、认证方式、功能点
```

同 IP 不同 Host、证书 SAN、跳转与页脚域、独立端口上的另一套 UI，都是独立对象。API 还要记版本前缀、文档口、移动端/旧版是否仍活。

清单状态：存活 / 非存活 / 同皮已代表 / 待测 / 深挖中。未完成用 todo，完成一项勾一项。漏测等于范围没做完。

**存活判定：** 探不通、超时、停放页、无业务响应 = 非存活。401、403、登录墙、管理台挑战页 = **活站**，不要丢掉。目录 403 不等于文件不存在。

---

## 3. 怎么测（浅打点，当场做）

看见什么，就用对应方式打第一枪。第一枪同步；要跟到影响或要大量尝试，再外派。

| 看见 | 当场怎么测 | 何时丢给子 Agent |
|------|------------|------------------|
| 未登录入口 / 调试 / 文档 / 备份 | 直接取，看真实回包 | 大量路径猜测、备份枚举 |
| 登录墙 | 找未登录 API、跳转后的业务 host、JS 网关；不磨验证码 | 多身份、重置/改绑链 |
| ID / 租户 / 对象字段 | 换邻号、空、0，对照基线 | 批量枚举、双会话对照 |
| 文件名 / 路径 | 读已知非敏感文件证明 | 深路径、打包源码 |
| URL / 回调 / 预览 | 证明会对外或对内发请求 | 内网面、云元数据链 |
| 搜索 / 过滤 / 排序 | 基线 vs 差异（内容、条数、耗时） | 确认后的数据面取证 |
| 模板 / 渲染字段 | 无害运算回显 | 引擎确认与命令级证据 |
| 写死钥 / 演示号 / 盐 | 记下并做一次对照 | 认钥后的只读影响证明 |
| 中间件 / 高危端口 | 见了再跟默认口或未授权面 | 服务内深挖 |

根据参数语义来决定测试点：文件名→文件面，URL→服务端请求，模板→渲染，ID/租户→授权。有过滤说明功能真实存在，换位置或编码再试，不要把 WAF 当终点。

浅打点也要对照基线（状态、长度、关键字段、耗时）。只报异常不够；能当场拿到影响证据就当场拿。不可逆破坏不做。

## 4. 扩张通道（长耗时，默认异步）

互不依赖，能并行就并行。

| 通道 | 去做 | 回流后主线加什么 todo |
|------|------|------------------------|
| 解析与子域 | DNS、子域、证书名 | 每个新名字做入口探测 |
| 同 IP / 虚拟宿主 | 换 Host | 新站点进全站流程 |
| 端口与服务 | 开放端口 + 指纹 | Web 外管理面/数据面浅探 |
| 爬取 | 有界深爬；SPA 看运行态或抽 JS | 新路径/表单分类打点 |
| 猜测 | 目录、备份、调试、文档、版本管理 | 命中则按第 3 节测 |
| 历史 | 旧页面、旧 path、旧 host | 现网是否仍通，通了就测 |
| JS / 前端包 | 路由、前缀、隐藏菜单、盐、演示号、sourcemap | 钥匙对照、未挂入口探测 |
| 文档与旧版 API | OpenAPI/GraphQL、v1/v2、mobile/legacy | 文档有的实现是否仍活 |
| 代码仓 | 公开仓、暴露的 git 元数据、CI、包名 | 密钥对照、模块入口 |

全量模板扫描不当进度。已知组件需要时再收窄去对，命中仍要在当前目标亲手验证。

## 5. 可深入点与场景（外派深挖）

这些形态不要只记一笔就走。主线建 todo，子 Agent 挖，挖完回流再拆下一层 todo：

- 历史快照或旧构建里的废弃 path、旧 host、旧签名
- 前端包、异步分片里的隐藏路由和未挂菜单接口
- 证书 SAN、跳转参数带出的另一套网关或身份子域
- 登录壳后的未登录前缀、SSO 壳后仍活的账密口、自定义身份头
- 运营配置 / 落地 JSON 里的票、演示租户、跳转 token
- 文档、Demo、依赖包里写死的钥或样例报文
- 列表有可见性过滤，详情/预览/导出/搜索不走同一闸
- 对象存储代理、预签名、桶策略过宽
- 版本管理：目录 403、单文件 200
- 悬空 CNAME/NS/MX：指纹到“可声明”才往下；私有 403 不是接管
- 中间件或高危端口见了再跟，不为表去全端口盲打

看别人不看的地方：错误页、管理 path、旧版本、移动端 API。

## 6. 子 Agent 与 todo 增生

主线：第一拍 HTTP、说清这摊、浅打点、收回流、**根据回流创建更多 todo**、保持有活任务在跑。

| 子任务 | 长耗时做什么 | 回流后主线必须做 |
|--------|----------------|------------------|
| 被动扩张 | 子域、证书、搜索、历史、公开仓 | 每个新活面建「入口探测」todo |
| 端口与服务 | 扫描、指纹、非 Web 入口 | 每个新端口建「浅探」todo |
| 深爬与猜测 | 链接/表单/目录/备份/调试/文档 | 按第 3 节分类打点或再外派 |
| JS 抽钥匙 | 路由、前缀、盐、演示号、sourcemap | 钥匙对照 + 未挂入口探测 todo |
| 深挖单点 | 用户点名的可深入链（多身份、取证、枚举） | 结论入库；半截线索再拆 todo |

约定：

- 子 Agent 带回的是资产、线索、已做的探测与证据，不是“建议以后再看”的空话。
- 主线拿到回流，同一轮就要改清单、加 todo、必要时再拉新的子 Agent。这是增生，不是收工。
- 子 Agent 不要再开一层无关测绘工厂。
- 主线在瘦壳上 15–20 分钟无新入口，换下一条活面。抽 JS、建对象图、拆回流 todo 不算空转。
- 场上应同时有：主线短打点 + 至少一类异步扩张或深挖。断了一头就补上。

## 7. 进站细节

- **别在有验证码的登录表单上无限尝试：** 活站先找未登录业务 API、跳转后的业务 host、JS 网关。发会话/重置/改绑有入口则建 todo 或外派，不在验证码上耗。
- **同皮站点：** 登录壳一样的留两三个代表做差分，不要每个同皮再开全套。
- **回包进队列：** 响应里新出现的 id、下载地址、token、内部 host、角色字段，立刻当新资产并加 todo。
- **半截继续跟：** 文件通道通了跟业务 API；抄到钥做对照；WAF/403 换编码或换位置。跟不动就外派，不要停在半截当结束。
- **JS 不只抽 path：** 硬编码钥、密文 ID 的前端公钥、hidden 路由、演示号都是钥匙，当场对照或外派取证。

---

## 8. 禁止

- 等子域或全端口结束才访问 80/443
- 短耗时也丢给子 Agent 空转；长耗时却堵在主线
- 子 Agent 回流了却不拆新 todo
- 把指纹、标题、模板命中写成已确认漏洞
- 把 401/403/登录墙当死站
- 目录 403 就停，不再取具体文件
- 全量扫描器当本站矩阵
- 用优先级丢掉子域、子系统、旧版 API、移动端
- 问“要不要继续”来停工；缺对照账号就降级测能测的
- 把范围理解成只测用户粘贴的那一条 path
