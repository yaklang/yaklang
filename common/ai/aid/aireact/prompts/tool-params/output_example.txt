# Example 1: Simple JSON Params (Tool)
```json
{
  "@action": "call-tool",
  "tool": "<selected_tool_name>",
  "identifier": "list_directory",
  "params": {
    "path": "./workspace"
  },
  "call_expectations": "~3s, success when the target directory listing is returned"
}
```

# Example 2: JSON + AITAG Hybrid (Tool)
```json
{
  "@action": "call-tool",
  "tool": "<selected_tool_name>",
  "identifier": "run_script",
  "params": {
    "timeout": 30
  }
}
```

```text
<|TOOL_PARAM_script_CURRENT_NONCE|>
... raw block content ...
<|TOOL_PARAM_script_END_CURRENT_NONCE|>
```

Replace `<selected_tool_name>` with the selected tool name and `CURRENT_NONCE` with the current nonce from the dynamic section. Include the complete block in this response.

# Example 3: AI Blueprint Params
```json

  "blueprint": "blueprint_name",
  "params": {
    "param1": "value1",
    "param2": "value2"
  }
}
```
